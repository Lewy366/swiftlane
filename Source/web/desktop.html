Shortcut address

iPhone: “Send to PC” Shortcut

Adds Swiftlane to the iPhone share sheet, like AirDrop. On Android (or any phone), just use the web app from the QR code; add it to your home screen from the browser menu.

  1. Open Shortcuts → +, name it Send to PC, turn on Show in Share Sheet.
  2. Add Repeat with Each → Shortcut Input.
  3. Inside: URL Encode → Repeat Item → pick its Name.
  4. Then Get Contents of URL: the Shortcut address (copy button) + URL Encoded Text. Method POST, header X-Token = pairing code, body File → Repeat Item.

The full step-by-step guide is in README.md in the project folder.
